# 评测七步引导

内置离线 HTML 动画，时长 180 秒。沿用“观看评测引导”入口、宿主弹窗与浏览器弹窗回退，不发送业务请求。

## 内容和依据

本片根据 2026-11-14 的真实运行记录重建画面，并非原屏幕录像。演示技能副本预置了商品金额误取整单金额的错误。

- 用例：EC-20261114-0006。
- 修复前：ER-20261114-203105，91 分，1/1 通过，回答 2 件 / 5.00 元 / 5.00 元。
- 复测后：ER-20261114-203710，100 分，1/1 通过，回答 2 件 / 4.00 元 / 5.00 元。
- 本次执行和判定均为“快速”，用例和样本不变。只展示这条用例的结果，不代表所有场景都已验证。
- 达到 60 分即通过不等于所有业务条件都正确。此处不启用红线，也不将两次通过演成失败后通过。

## 播放与集成

`index.html`、`player.css`、`player.js` 提供画面与时间轴；`locales.js` 提供简体、繁体、英语文案。旧 `icons.js` 未被新版引用。

支持播放/暂停、重播、进度拖动、七步导航、前后步骤、空格和左右方向键。选择步骤暂停，点击画面中的操作继续播放。重新打开从 00:00 待播放开始；页面隐藏自动暂停；减少动态效果设置禁用运行条动画。

父窗口消息：`{type:"lingee-evaluation-guide", action}`，action 为 `replay`、`pause`、`light`、`dark`。仅接受来自 parent 的消息。子窗口发送 `ready` 和 `escape`，父窗口核对来源。

保持 script-only sandbox 与 CSP，禁止网络连接和表单。动画不接收账号、会话、鉴权或业务接口参数。
