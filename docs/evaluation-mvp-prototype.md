# 评测 MVP 交互原型

版本：v1.0.0｜更新日期：2026-11-01｜产品阶段：MVP

需求依据：[产品需求文档 v1.0.0](../../deliverables/灵基Build评测功能需求文档-v1.0.0.md)。配套验证：[详细验收清单 v1.0.0](../../deliverables/灵基Build评测功能详细验收清单-v1.0.0.md)。

本文说明当前原型的体验路径、规则对应和模拟边界。产品范围与业务规则由需求正文定义；验收清单列出场景及预期结果；原型用于呈现交互，不代表真实服务已经完成。

## 一、体验路径

1. 启动 `bun run dev`，打开 `http://127.0.0.1:5180/dev/skill` 或 `/dev/agent`。
2. 从技能或智能体卡片菜单、详情中的“评测 Beta”进入独立工作区。Beta 是入口标识，MVP 是本版本的产品阶段；工作区标题显示对象名称和运行环境。
3. 新增用例可选择手动创建或对话生成。点击用例名称先查看详情，再按需编辑；“添加示例用例（仅原型）”用于体验模拟结果。
4. 运行当前对象全部用例，或运行跨页勾选的用例。搜索不缩小“全部运行”范围；改变搜索清空选择。
5. 从运行记录查看进度、逐轮回复、澄清过程、工具记录及逐项标准证据。运行中或判定中可请求停止，保留已经形成的结果。
6. 运行结束或确认停止后预览报告，下载可离线打开的 HTML。预览与下载使用相同内容和版式。
7. 运行详情顶部提供“重新运行”下拉按钮，包含“本次全部用例（N）”和“不通过用例（N）”。前者选择原记录全部用例，后者仅选择本次明确不通过的用例，与“修复问题”范围一致，不包含无法判定；数量为历史范围内的用例数，没有不通过用例时对应菜单项禁用。结果列表中，不通过和无法判定行提供“重新运行”，仅运行该条；通过行不提供。单条用例结果详情不再提供重新运行入口。选择范围后直接启动，不再确认正常运行范围。所有入口读取所选用例与对象最新已保存内容，使用当前沙箱环境，遵守同对象活动运行限制；未保存编辑不参与，新运行不改写旧记录。仅所选范围内有用例删除时列明缺失与剩余范围并确认；所选用例全部删除则禁止重跑并引导返回用例列表。 单例修复返回原运行结果列表并定位对应行；运行记录的时间标题与“查看结果”进入同一详情。
8. 技能和智能体的明确不通过结果均可携带失败证据进入原对象的开发对话。请求先预填，由用户发送，再通过对话分析并修改；修改直接写入原对象，无需用户再次保存。用户通过原对象卡片检查修改，再点击“返回运行记录”手动复测。

## 三、输入、附件与草稿

名称和每轮用户输入必填，不能仅为空白；至少一轮对话，全用例至少一条轮次或整体标准。已添加的标准及澄清问答须完整有效。支持添加、排序、折叠和删除轮次，不能删除最后一轮；删除轮次、标准或澄清回复均确认影响。

不设置没有依据的固定字符数或附件容量限制；正则辅助按用户指定的数字段长度生成，不附加固定上限，空示例也按空文本验证。附件保存失败仍需提示原因并支持重试；任一附件组上传中不能保存用例。分页条数属于界面展示参数，不是用例数量限制；时间快捷选项不限制全部时间或自定义查询。

会话附件在用例开始时提供，本轮附件随对应输入提供，不能提前使用后轮附件。用例与运行通过附件引用保留材料；从当前用例移除附件不删除历史运行仍使用的附件。输入附件可下载，产物文件不提供下载。附件名不能当作已读取内容，也不能当作生成产物证据。

从详情进入编辑，保存或取消后回到详情；从列表进入编辑则回到列表。手动用例与对话草稿未保存时，站内离开、关闭或刷新均须提醒，确认放弃后才丢弃修改。校验失败展开并定位首个错误；存储失败保留编辑输入及选择，停留编辑并持续说明错误，不显示成功，恢复存储后可重试。

对话生成进入原对象所属项目，项目缺失不回退。草稿先预览、编辑、选择，再加入正式列表，不自动启动运行。生成中禁止编辑或加入；编辑未保存时先保存或取消，再继续对话。批量加入先检查全部内容，任一无效则整批不写入。

草稿区分待加入、已加入、草稿修改、正式用例修改、双方修改、关联用例删除。无变化不能重复加入；覆盖或重新加入须确认，使用当前草稿完整替换，不自动合并；确认期间正式用例又变化则中止覆盖。加入关联或正式用例写入失败时恢复原记录，保留草稿和选择；回退写入也失败时明确说明关联记录尚未恢复到存储，不显示成功。成功或失败均不改写历史运行。停止生成保留此前已完成草稿。

## 四、执行、判定与停止

仅允许沙箱启动和重跑；环境未知或生产环境均不可执行。每次运行保留当次用例、顺序、标准、澄清、附件、环境及判定规则，后续编辑或删除不改写历史。正式执行还应固定原对象的最新保存内容并记录标识；当前原型未接入此能力，显示未记录。

不同用例和运行隔离对话及产物，同一用例各轮共享上下文。仅本轮业务正常结束并取得实际结果后推进下一轮；澄清等待或答复提交不代表结束。标准不通过本身不阻止后续业务轮次；执行异常或澄清阻断终止当前用例，其他用例继续，停止整次运行除外。

轮次语义检查截至本轮的实际过程，不读取后轮；整体语义只在全部业务轮次正常结束后检查完整过程。对象声称已完成不能代替业务成功证据。只有明确含条件的语义标准且证据确认条件未发生，才可判不适用；条件不明为无法判定。

关键词和正则只检查本轮最终回复，整体只检查最后一轮最终回复，不混入输入、工具或文件内容。保留大小写、空格和排版标记，只统一换行符。关键词按字面、区分大小写；正则不自动启用忽略大小写、多行锚点或跨行匹配。明确为空的回复可以检查，缺失回复不能通过否定匹配得出结论。

文件检查使用用例产物区域内的相对路径，拒绝绝对路径或越界路径。在本轮正常结束、下一轮开始前检查；整体在最后一轮正常结束后检查。保存期望路径、实际路径、时点及存在性结果；后轮修改不改变前轮记录。“不存在”也需要检查成功，无法访问、超时、未到时点或缺少证据均无法判定，不用停止后的文件状态替代。

任一适用标准失败则用例不通过；没有失败但存在无法判定、全部不适用或执行不完整时，用例无法判定；执行完整且全部适用标准通过才通过。执行状态与业务判定分开展示。

判定超时或无效可有限重试，只使用已有证据，不重复业务操作；仍失败则无法判定。停止或异常后不新建整体判定，已有结论保留，未完成标准说明原因并结束为无法判定；迟到结果不能覆盖终态。具体重试次数和时间参数须有实际依据，不能由演示计时推导。

运行中、判定中、停止处理中、停止待核实均属活动状态，阻止同对象再次启动或删除，当前运行不开放修复和最终报告。停止先进入处理中，确认全部业务、待答、判定和重试结束后才显示已停止；无法确认时保持待核实。模拟核实按钮仅供原型演示，不证明后台任务真的终止。

## 五、澄清回复

只有实际等待用户回答时才使用当前轮次配置，普通疑问句不触发。结合问题含义、上下文、选项和约束唯一匹配，不猜测答案或编造配置外的事实。

支持自由文本、单选、多选、一次多题及可明确拆分的多事项。单选对应一个选项，多选对应一个或多个选项；仅允许自定义时可回答选项外内容。整批全部匹配且符合要求后按提问顺序提交；任一失败则不提交部分答案，已匹配项说明未提交。

同一请求重复通知不重复回复或计数，新发起的相同问题计为新请求，多题一批算一次；同一配置可重复使用。自动回复有界，达到已确认的系统限制后不再回复新请求并终止当前用例，下一轮重新计数；本版不增加用户配置项，也不预设无依据的固定次数。

只有确认接收才显示已回复。未匹配、歧义、选项冲突、无法拆分、超限、提交失败或接收不明等情况终止当前用例，后续轮次未执行，其他用例继续。登录、授权和服务来源选择不能使用业务澄清自动回答。

配置与实际过程分别展示，实际过程记录问题、上下文、题型、选项、匹配配置、拟答、提交结果及异常。基本过程和异常原因属于产品要求，扩展展示不影响 C01–C12 的支持范围。当前原型只呈现模拟过程，未验证真实匹配、去重、批量提交和接收确认。

## 六、报告与消耗点数

页面和报告统一使用“消耗点数”，区分执行、轮次判定和整体判定。实际零点数、未知和部分已知点数分开显示，不将缺失补零，不用模型成本估算代替点数记录。

报告读取历史快照，包括运行信息、结论、问题清单、用例概览、逐轮及逐项证据、消耗点数和判定规则。历史缺失的信息显示未记录，不补写当前值。停止、异常、不完整或没有结果都不能表述为全部通过。

报告可离线打开，目录可定位、证据可折叠，用户文本经过转义。附件只展示信息，不打包输入原文件或产物。已下载报告固定当时内容，系统更新消耗点数后需重新下载。

点数由系统自动更新，不提供“刷新点数”按钮。运行期间自动查询，结束后继续有限补查；达到重试上限后停止本轮查询，重新打开未完整的运行记录时自动检查并更新。只查询点数，不新增运行、不重新判定或重复业务操作；并发查询去重。查询失败或暂未完整不影响查看结果、修复与重跑。

用户侧统一显示“统计中”“统计不完整”“暂未获取”。已获取部分时显示“已获取消耗点数：7.96 · 统计中”或“已获取消耗点数：7.96 · 统计不完整”；完整时显示“消耗点数：7.96”。没有任何金额时显示“消耗点数：统计中”或“消耗点数：暂未获取”，不能把未知写成零。不展示“快照”“计费标识”等实现术语。

原型每 5 秒查询一次，终态最多补查 3 次；页面重新进入未完整记录可开启新一轮有限查询。原型通过浏览器内调度模拟后台，关闭浏览器后不执行，正式产品由后台负责持续更新。查询成功同步更新金额、明细和时间，失败保留已有值。运行信息默认折叠，版本字段不再占据结果总览；原型演示工具默认折叠。

## 七、修复、重跑与删除

技能与智能体共用“修复问题”和单用例“去修复”的可用条件：原对象仍存在且可编辑，原运行已结束并有明确不通过。整次修复只带失败用例，单例只带对应证据；全部通过、仅无法判定或目标失效时说明原因。

修复会话绑定原对象类型、ID、所属项目和运行。技能使用技能开发入口，智能体使用智能体开发入口；预填但不自动发送，用户发送后通过开发对话分析问题并修改。会话恢复、同名对象或干扰提示均不能改变目标；目标失效时停止，不创建新对象。

先核对当前内容与历史依据，区分对象缺陷、标准问题、数据变化及环境问题；只修改确认属于原对象且可编辑的内容，不放宽标准，不默认改写智能体所挂载的技能或知识源。对话完成的修改直接写入原对象，无需用户再次点击保存。完成后显示原对象卡片及“返回运行记录”，用户检查修改结果后手动重跑，不自动提交、发布或复测。当前原型只模拟修改标记，不证明真实内容变更或持久化。

重跑包含原记录关联的全部用例，而非仅失败用例；使用原对象与这些用例的最新保存内容，产生新记录，旧记录保持不变。部分用例已删除时确认剩余范围，全部删除则不能重跑。

删除用例保留历史运行。删除对象永久清理其评测用例、运行、报告与消耗点数记录、编辑和生成草稿、评测生成及修复会话、消息和返回关联，并清理无其他评测引用的附件。其他对象、普通会话及仍被引用附件不受影响，已下载报告无法撤回。

删除前确认完整范围及不可恢复性。有活动评测、相关生成或待答会话时先停止并确认结束；批量操作任一阻断则整批不删除。保存或附件清理失败不移除对象、不显示成功，允许重试。删除成功后旧链接不能恢复入口。

## 八、原型实现边界

- 当前为 React 前端与本地模拟数据，不连接真实模型、MCP、ERP 或评测引擎。固定示例演示结果，自定义或编辑后的用例缺少真实证据时显示无法判定。
- 用例、运行、编辑草稿、评测生成及修复关联保存在浏览器 localStorage，附件保存在 IndexedDB。按对象 ID 区分本地数据；草稿加入采用本地失败回退，尚不具备跨记录原子事务，写入过程中意外关闭仍需正式服务保障。真实用户隔离、服务器持久化和权限控制须由正式服务证明。
- 运行状态、判定失败、停止核实及点数查询使用模拟过程。演示计时、示例点数和分页参数不构成产品的容量、次数或时间限制。
- 未接入真实执行会话、工作区隔离、对象内容固定、逐轮文件检查、语义判定、澄清匹配、取消确认或点数服务。相关接入要求见清单 T01–T09。
- 修复剧本按原 ID 和项目标记原对象有修改，智能体记录待提交变更；不新增对象，不提交或发布。这些标记保存在内存中，刷新恢复初始对象数据；修复会话和返回关联可恢复。模拟标记不证明内容已修复。
- “添加示例用例”、停止／核实模拟、点数状态模拟等辅助入口标“仅原型”。不包含自动改进、候选副本自动采纳、自动复测／发布、分类分级、回归标签、评分权重、工具参数断言、独立参考文件或产物内容检查与下载。

## 九、核对与验证

沿用现有视觉组件、系统字体与交互方式；状态有文字，键盘焦点清晰，长文本与窄屏可操作。删除、放弃编辑和覆盖草稿使用一致的确认。成功提示可短暂显示，保存及操作失败说明持续可见并保留当前工作。

- `bun run build`：检查 TypeScript 和生产构建。
